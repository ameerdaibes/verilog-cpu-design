# Phase 1 — Core CPU Components

Phase 1 focuses on implementing and testing the CPU's fundamental components.

## Included Modules

- `ALU.v` — 32-bit arithmetic logic unit
- `RegisterFile.v` — 16-register file with synchronous writes
- `tb_ALU.v` — ALU testbench
- `tb_RegisterFile.v` — register-file testbench
- ModelSim waveform scripts

## Main Concepts

- Arithmetic and logical operations
- Shift operations
- Comparison
- Carry and overflow detection
- Zero and negative flags
- Register read/write behavior
- RTL simulation and waveform analysis
