# Phase 3 — CPU Control & Program Flow

Phase 3 extends the datapath with a dedicated control unit and program-flow support.

## Included Modules

- `ALU.v`
- `ControlUnit.v`
- `DataMemory.v`
- `Datapath.v`
- `InstructionMemory.v`
- `PC.v`
- `RegisterFile.v`
- `SignExtend.v`
- `tb_Datapath.v`

## Main Concepts

- Centralized instruction decoding
- R-type operations
- Immediate instructions
- Load/store operations
- Conditional branches
- Jump instructions
- Program-counter selection
- Integrated processor simulation
