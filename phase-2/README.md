# Phase 2 — Integrated Datapath

Phase 2 connects the core CPU components into a functional datapath.

## Included Modules

- `ALU.v`
- `DataMemory.v`
- `Datapath.v`
- `InstructionMemory.v`
- `PC.v`
- `RegisterFile.v`
- `SignExtend.v`
- `tb_Datapath.v`

## Main Concepts

- Program-counter sequencing
- Instruction fetch
- Register-file access
- Immediate sign extension
- ALU operand selection
- Load/store behavior
- Write-back data selection
- Basic instruction decoding
